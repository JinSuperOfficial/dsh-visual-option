## 简介（中文）

DSH Visual Option 是给 DeepSeek Harness Web GUI 写的一个开源插件
它把 ask-user-question 从一串纯文本选项，变成可以预览、点选、写备注、做测验的界面

不用再靠想象去猜 AI 生成的页面长什么样，两套方案直接并排摆出来
选完还能顺手写一句备注，模型拿到的是结构化答案，而不是又一轮对话

主要能力
· 五种模式：单选 / 多选 / 填空 / 确认 / 测验
· 三种预览：远程 URL、本地路径、内联 HTML / PHP
· 每个选项都能单独写备注，提示按需展开
· 底部自带「其他」自由填写和「跳过」
· 随时「提问」，把问题打回主对话
· 测验模式：提交后只显示对错和得分，不泄露正确答案
· 六种语言：中文 / 繁体 / English / 日本語 / Español / Français
· 原生弹窗，支持 Esc 取消、焦点环、宽度自适应

## Description (English)

DSH Visual Option is an open-source plugin for the DeepSeek Harness Web GUI
It turns ask-user-question from a block of plain text into a dialog where you can preview, pick, annotate and even take a quiz

No more guessing what the AI actually generated: two landing pages are rendered side by side
Pick one, leave a note, and the model gets structured data instead of another chat turn

What it does
· Five modes: single, multi, fill, confirm, test
· Three preview kinds: remote URL, local path, inline HTML / PHP
· Per-option notes, hints revealed on demand
· Built-in "Other" box and per-question skip
· Ask back to the main conversation at any time
· Test mode: right or wrong plus a score, never the answers
· Six languages: Chinese, Traditional Chinese, English, Japanese, Spanish, French
· Native dialog: Esc, focus ring, adaptive preview width
